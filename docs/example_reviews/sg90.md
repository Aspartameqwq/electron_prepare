# 例程评审：SG90 舵机（P7 参考）

**source_id**：`lckfb-tmx-sg90`
**来源**：`examples_and_documents/立创·天猛星MSPM0G3507开发板【模块移植代码】/控制类/SG90舵机/`
**结构**：`BSP/src/bsp_sg90.c` + `BSP/inc/bsp_sg90.h`；`empty.c`；`empty.syscfg`
**SDK**：mspm0_sdk@2.02.00.05 / SysConfig 1.21.0（旧）

## 定时器频率结论（v7.2 纠偏：原"约 40 Hz"结论无效，标 `CALCULATION_UNVERIFIED`）

**证据（SOURCE_FACT，来自 `empty.syscfg`）**：
- 启用了 40MHz HFXT + SYSPLL 时钟树（`HSCLKMUX_SYSPLL2X`、`SYSPLLMUX_HFCLK`、HFXT）；
- PWM：`clockDivider=8, clockPrescale=250, timerCount=400`（TIMG0，CCP0=PA12）。

**结论（CALCULATED，未闭环）**：
- 正确公式：`timer_clk = source_clk / (divider × (prescale+1))`；
- 原评审按默认 32MHz 推算"约 40Hz" **忽略了已启用的 HFXT/SYSPLL 时钟树**，结论无效；
- 在读取 SysConfig 计算频率 / 生成文件时钟注释 / 逻辑分析仪实测之前，**不写任何具体频率估算值**；状态 = `CALCULATION_UNVERIFIED`。**仅记录：该配置与 50Hz 要求不一致且未闭环**（`clockDivider=8, clockPrescale=250, timerCount=400` 是否产生 50Hz 取决于真实 timer source / 计数模式 / 周期端点 / 极性，均未确认）。

**源码注释与配置不一致（SOURCE_FACT）**：`bsp_sg90.c` 把 10~50 count 解释为 0.5~2.5ms，与现有时钟配置对不上。P7 必须**用当前 SDK 与 `control.syscfg` 重新生成 50Hz 配置**并实测，不得采用本例程频率/脉宽参数。

## 可取之处（借鉴）

1. 角度限幅：`if(angle > 180) angle = 180` ——基本越界保护。
2. float 角度→计数值映射 + `+0.5f` 四舍五入——计算清晰（但脉宽基准需按实测安全限位重算）。
3. 生成宏用法：`DL_TimerG_setCaptureCompareValue(PWM_SG90_INST, cnt, GPIO_PWM_SG90_C0_IDX)` ——规范。

## 不足之处（弃用）

1. **`timerStartTimer = true`**：上电即输出 → 违反本项目"PWM 初始化后不得自动启动、上电不产生跳向极限的脉冲"。
2. **无渐变（slew）**：`Set_Servo_Angle` 直接跳目标值 → 本项目要求 `servo_service()` 按 `max_slew_us_per_s` 渐进。
3. **无 enable/disable**：驱动常开，无"未校准前不输出"、无 `servo_fault_policy`。
4. **全局变量 `Servo_Angle`（非 static）**：封装差。
5. **无实测安全限位**：0~180° 直接映射，未按 `servo_probe_pulse_us` / 实测 `servo_safe_min/max` 校准。

## 与 PLAN.md 冲突点（必不照搬）

| 本例子 | 本项目要求 |
|---|---|
| 频率 `CALCULATION_UNVERIFIED`（与 50Hz 不一致且未闭环） | 50Hz，P7 按**当时实际系统时钟**重新生成并实测（**不预设 80MHz**，80MHz 属 E3） |
| 直接跳目标 | `servo_service()` 按 slew 渐变 |
| 无 enable/disable | `servo_enable(channel)` 显式；未设置目标 enable 报错 |
| 0~180° 映射 0.5~2.5ms | `servo_probe_pulse_us` + 实测 `servo_safe_min/max` |
| timerStartTimer=true | 初始化后禁自动启动 |

> **注意**：该例程的时钟树（HFXT/SYSPLL 80MHz）**不得用于 P1/P2**；80MHz 属可选扩展 **E3**（PLAN.md 已定）。

## 借鉴建议（应用到本项目）

- 角度→脉宽映射思路可参考，但重写为 `drivers/servo_pwm`：`set_pulse_us`（立即/校准）与 `set_target_us`（渐变）分离；共享定时器单通道禁用；P7 host 转换测试覆盖预分频/舍入。
- 引脚/接线查 `empty.syscfg`（PA12 等，板级正确性参考），以本项目 `control.syscfg` 为准。

**TI 文件规则**：`source/ti/driverlib/`＝供应商源码，**不修改**；`ti_msp_dl_config.c/h`＝SysConfig 生成产物，**不手工编辑**（改 `.syscfg` 后重新生成）；`DL_*`＝API 名称，不是文件。禁用单通道须核实 PWM 极性与 compare=0 真实输出，优先用 DriverLib 通道输出禁用机制，不靠停整个共享定时器。
