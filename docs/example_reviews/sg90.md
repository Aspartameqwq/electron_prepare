# 例程评审：SG90 舵机（P7 参考）

**来源**：`examples_and_documents/立创·天猛星MSPM0G3507开发板【模块移植代码】/控制类/SG90舵机/`
**结构**：`BSP/inc/bsp_sg90.h` + `BSP/src/bsp_sg90.c`；`empty.c`；`empty.syscfg`
**SDK**：mspm0_sdk@2.02.00.05（旧）

## 可取之处（借鉴）

1. **角度限幅**：`if(angle > 180) angle = 180` —— 基本越界保护。
2. **float 角度→计数值映射**：`min_count + (angle/180)*range`，`+0.5f` 四舍五入 —— 计算清晰。
3. **生成宏用法**：`DL_TimerG_setCaptureCompareValue(PWM_SG90_INST, cnt, GPIO_PWM_SG90_C0_IDX)` —— 规范。
4. **中文注释含脉冲宽度对照表**（0.5ms→0° … 2.5ms→180°）—— 便于理解。

## 不足之处（弃用）

1. **定时器配置 ≈ 40Hz 而非 50Hz**：`clockDivider=8, clockPrescale=250, timerCount=400` → 若 HFCLK 32MHz，tick=16kHz、周期=400/16k=25ms=40Hz（SG90 需 50Hz/20ms）；且 10~50 count → 0.625~3.125ms 脉宽，超出 SG90 常见 0.5~2.5ms 安全范围。**其注释（50Hz）与实际配置不符**。
2. **`timerStartTimer = true`**：上电即输出 → 违反本项目"PWM 初始化后不得自动启动、上电不产生跳向极限的脉冲"。
3. **无渐变（slew）**：`Set_Servo_Angle` 直接跳目标值；demo 靠主循环 `i++`/10ms 才显得慢 → 本项目要求 `max_slew_us_per_s` 由 `servo_service()` 渐进逼近。
4. **无 enable/disable**：驱动常开，无"未校准前不输出"、无 `servo_fault_policy`（HOLD/PARK 属上层）。
5. **全局变量 `Servo_Angle`（非 static）**：封装差，外部可改。
6. **无实测安全限位**：0~180° 直接映射 0.5~2.5ms，未按 `servo_probe_pulse_us`/实测 `servo_safe_min/max` 校准。

## 与 PLAN.md 冲突点（必不照搬）

| 本例子 | 本项目要求 |
|---|---|
| prescale 250 → ~40Hz | 50Hz，预分频由 SysConfig 算 |
| 直接跳目标 | `servo_service()` 按 `max_slew_us_per_s` 渐变 |
| 无 enable/disable | `servo_enable(channel)` 显式；未设置目标 enable 报错 |
| 0~180° 映射 0.5~2.5ms | `servo_probe_pulse_us` + 实测 `servo_safe_min/max` |
| timerStartTimer=true | 初始化后禁自动启动 |

## 借鉴建议（应用到本项目）

- **角度→脉宽映射思路**可参考，但重写为 `drivers/servo_pwm`：`set_pulse_us`（立即/校准）与 `set_target_us`（渐变）分离；定时器共享语义（单通道禁用不停共享定时器）；P7 host 转换测试覆盖预分频/舍入。
- **引脚/接线**查 `empty.syscfg`（PA12 等，板级正确性），以本项目 `control.syscfg` 为准。

## TI 库铁律

TI DriverLib 与生成文件**绝不允许修改**；禁用单通道须核实 PWM 极性与 compare=0 真实输出，优先用 DriverLib 通道输出禁用机制，不靠停整个共享定时器。
