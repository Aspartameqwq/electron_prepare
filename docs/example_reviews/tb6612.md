# 例程评审：TB6612 电机驱动模块（P4 参考）

**来源**：`examples_and_documents/立创·天猛星MSPM0G3507开发板【模块移植代码】/控制类/TB6612电机驱动模块/`
**结构**：`BSP/inc/bsp_tb6612.h` + `BSP/src/bsp_tb6612.c`；`Board/board.c/h`（通用）；`empty.c`（demo）；`empty.syscfg`
**SDK**：mspm0_sdk@2.02.00.05（旧）

## 可取之处（借鉴）

1. **方向与速度分离**：方向走 GPIO（AIN1/AIN2/BIN1/BIN2），速度走定时器 PWM——接口清晰（`AO_Control(dir, speed)`）。
2. **DriverLib 生成宏用法正确**：`DL_TimerG_setCaptureCompareValue(PWM_0_INST, speed, GPIO_PWM_0_C1_IDX)`——正是"用生成宏、不写死寄存器"的规范用法，与本项目规则一致。
3. **syscfg 80MHz 时钟树**：HFXT 40MHz(PA5/PA6) + SYSPLL2X + UDIV/2，与 mspm0-ccs skill 已验证的 80MHz 模式一致，可作 P2 参考。
4. **UART0=PA10/PA11@115200、PB22 LED**：与天猛星板级一致（CH340 调试口）。
5. **参数校验**：`if(speed > 999 || dir > 1)` 打印错误（虽不 return 前做更多，但有基本保护）。
6. **中文函数头注释**：格式统一、可读性好。

## 不足之处（弃用）

1. **用 TIMA1 而非 TIMA0**：本项目资源规划 TIMA0 承担电机 PWM；TIMA1 备用。
2. **`timerStartTimer = true`**：定时器上电即自动启动 → 违反本项目"PWM 初始化后不得自动启动、执行器默认禁用"。
3. **`TB6612_Motor_Stop()` 实际是 BRAKE**：`AIN1=AIN2=1` 为 TB6612 制动模式，不是本项目"零命令默认 COAST"语义。
4. **无 STBY 控制**：STBY 未接 GPIO（默认悬空/上拉），无法通过 STBY 拉低做紧急停止 → 违反本项目 STBY 硬件门禁。
5. **无换向死区**：先写方向 GPIO 立即更新 PWM，正反转直接切换会反冲 → 本项目 actuator_guard 需 20ms 零输出。
6. **速度单位**：raw 0~999（compare 值），未归一化 0~10000 → 本项目 `motor_command_t` 语义。
7. **error 分支只打印不处理**：`AO_Control parameter error!!!` 后仍 return，调用方无法感知。

## 与 PLAN.md 冲突点（必不照搬）

| 本例子 | 本项目要求 |
|---|---|
| TIMA1 + timerStartTimer=true | TIMA0，禁自动启动 |
| Stop=BRAKE（IN=高） | 零命令=COAST；STBY 低 |
| 无 STBY GPIO | STBY 必须 GPIO+外部下拉，仅 RUNNING 拉高 |
| 换向立即切换 | 换向经 20ms 零输出死区 |
| speed 0~999 | duty 0~10000 归一化 |

## 借鉴建议（应用到本项目）

- **接口形态**：参考 `AO_Control/BO_Control(dir, speed)` 的方向/速度分离，但重写为 `motor_set_command(motor_id_t, motor_command_t)` + `actuator_guard`。
- **生成宏用法**：沿用 `DL_TimerG_setCaptureCompareValue(INST, val, IDX)` 模式，实例名以本项目 `control.syscfg` 为准。
- **80MHz 时钟树**：P2 如需可参考其 HFXT/SYSPLL 写法，但按 mspm0-ccs skill 的验证模式 + FCC 校验实现。

## TI 库铁律

TI DriverLib（`source/ti/driverlib/`、`ti_msp_dl_config.h/c`、`DL_*` API）**绝不允许修改**。仅通过 SysConfig + 生成宏使用；本项目适配全部在 `bsp/motor_tb6612` + `safety/actuator_guard` 层。
