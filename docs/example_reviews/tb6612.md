# 例程评审：TB6612 电机驱动模块（P4 参考）

**source_id**：`lckfb-tmx-tb6612`
**来源**：`examples_and_documents/立创·天猛星MSPM0G3507开发板【模块移植代码】/控制类/TB6612电机驱动模块/`
**结构**：`BSP/src/bsp_tb6612.c` + `BSP/inc/bsp_tb6612.h`；`Board/board.c/h`（通用）；`empty.c`；`empty.syscfg`
**SDK**：mspm0_sdk@2.02.00.05 / SysConfig 1.21.0（旧）

## STBY 描述（v7.2 纠偏：不得推断模块 PCB 接法）

**已确认事实（SOURCE_FACT，来自源码 + syscfg）**：
- 例程**没有配置 MCU 可控的 STBY GPIO**；
- 方向 GPIO（AIN1/AIN2/BIN1/BIN2）初始为高（`initialValue = SET`）；
- `TB6612_Motor_Stop()` 将两组方向输入都置高 → **短路制动**；
- PWM 定时器 `timerStartTimer = true` → 自动启动。

**不确认（INFERRED 禁止）**：模块 PCB 上 STBY 是悬空 / 上拉 / 直连高电平——**仅凭源码无法判断**，须查模块原理图或用万用表实测。**不得从源码推断"默认悬空/上拉"。**

## 可取之处（借鉴）

1. 方向与速度分离：方向 GPIO + 速度 PWM，接口清晰（`AO_Control(dir, speed)`）。
2. DriverLib 生成宏用法：`DL_TimerG_setCaptureCompareValue(PWM_0_INST, speed, GPIO_PWM_0_C1_IDX)` ——规范。
3. 参数校验：`if(speed > 999 || dir > 1)` 打印错误。
4. UART0=PA10/PA11@115200、PB22 LED——与天猛星板级一致（CH340 调试口）。
5. 中文函数头注释——可读性好。

## 不足之处（弃用）

1. **用 TIMA1 而非 TIMA0**：本项目资源规划 TIMA0 承担电机 PWM。
2. **`timerStartTimer = true`**：**定时器自动启动**；实际输出波形取决于 compare/period/invert/GPIO 复用生效时间/输出初始状态（**未验证**）→ 但仍可判定不符合本项目"执行器默认禁止输出、PWM 初始化后不得自动启动"要求。
3. **`TB6612_Motor_Stop()` 是 BRAKE 不是 COAST**：`AIN1=AIN2=1`（双高）为短路制动，本项目零命令默认 COAST。
4. **无换向死区**：先写方向 GPIO 立即更新 PWM，正反转切换会反冲 → 本项目 `actuator_guard` 需 20ms 零输出。
5. **复制粘贴 bug（SOURCE_FACT）**：`BO_Control()` 参数错误时打印的是 `"AO_Control parameter error!!!"`。
6. **error 分支只打印不返回状态**：调用方无法感知参数非法。
7. **速度单位**：raw 0~999，未归一化 0~10000。

## 与 PLAN.md 冲突点（必不照搬）

| 本例子 | 本项目要求 |
|---|---|
| TIMA1 + timerStartTimer=true | TIMA0，禁自动启动 |
| Stop=BRAKE（IN=高） | 零命令=COAST；STBY 低 |
| 无 STBY GPIO | STBY 必须 GPIO + 外部下拉，仅 RUNNING 拉高 |
| 换向立即切换 | 换向经 20ms 零输出死区 |
| speed 0~999 | duty 0~10000 归一化 |

> **注意**：该例程的 80MHz 时钟树（HFXT/SYSPLL）**不得推荐给 P2**；80MHz 属可选扩展 **E3**。P1/P2 保持默认时钟基线。

## 借鉴建议（应用到本项目）

- 接口形态（方向/速度分离）可参考，但重写为 `motor_set_command(motor_id_t, motor_command_t)` + `actuator_guard`（含换向死区、STBY 聚合）。
- 生成宏用法沿用，实例名以本项目 `control.syscfg` 为准。

**TI 文件规则**：`source/ti/driverlib/`＝供应商源码，**不修改**；`ti_msp_dl_config.c/h`＝SysConfig 生成产物，**不手工编辑**（改 `.syscfg` 后重新生成）；`DL_*`＝API 名称，不是文件。本项目适配写在自有 `bsp/motor_tb6612` + `safety/actuator_guard` 层。
