# 例程评审：MPU6050 六轴传感器（P9 参考）

**来源**：`examples_and_documents/立创·天猛星MSPM0G3507开发板【模块移植代码】/传感器类/MPU6050六轴传感器/`
**结构**：`BSP/src/bsp_mpu6050.c`（429 行）+ `BSP/inc/bsp_mpu6050.h`；**InvenSense DMP 栈**：`BSP/src/inv_mpu.c`（3028 行）+ `inv_mpu_dmp_motion_driver.c`（1382 行）；`empty.c`
**接口**：`MPU6050_Init / mpu_dmp_init / mpu_dmp_get_data(&pitch,&roll,&yaw)`
**地址**：0x68

## 可取之处（借鉴）

1. **寄存器初始化序列正确**（`MPU6050_Init`）：复位（PWR_MGMT_1=0x80）→ 唤醒（0x00）→ 关中断/关 I2C 主模式/关 FIFO → `MPU_Set_Gyro_Fsr / MPU_Set_Accel_Fsr / MPU_Set_LPF / MPU_Set_Rate` ——P9 初始化可直接参考（WHO_AM_I 校验见 `MPU6050ReadID`）。
2. **原始数据读取**：`MPU6050ReadGyro / MPU6050ReadAcc` 连续读 6 字节，思路正确。
3. **满量程/低通/采样率可配**：`MPU_Set_Gyro_Fsr / Accel_Fsr / LPF / Rate` 抽象清楚。

## 不足之处（弃用）

1. **软件 I2C（bit-bang）**：`IIC_Start/Stop/Send_Ack/WaitAck/Send_Byte` 手工模拟，未用硬件 I2C0 → 慢、阻塞、绕过硬件控制器；本项目用同步阻塞硬件 I2C（含 I2C_ERR_13）。
2. **DMP 栈 4400+ 行**：`inv_mpu.c` + `inv_mpu_dmp_motion_driver.c` 是 InvenSense 参考代码——重、旧，且 demo 把 `yaw` 当欧拉角直接打印（**无绝对 yaw，长时间漂移**）；本项目用"原始六轴 + 互补滤波 + 相对 yaw"，**不移植 DMP**。
3. **`while( mpu_dmp_init() )` 无限重试**：DMP 初始化失败会死循环（200ms 间隔）→ 若 MPU6050 缺失则**永远卡死**，违反本项目"设备缺失 → 有限超时返回"。
4. **hacky 类型转换**：`MPU6050_WriteReg(0x68, reg, 1, (uint8_t*)(fsr<<3))` 取临时 int 地址强转——UB/风格差。
5. **无校准/漂移处理**：只读原始+DMP，无静止零偏校准、无 `yaw_rel_valid`、无安装轴映射（右手系校验）——本项目 P9 均有要求。
6. **地址硬编码 0x68**。

## 与 PLAN.md 冲突点（必不照搬）

| 本例子 | 本项目要求 |
|---|---|
| 软件 I2C bit-bang | 同步阻塞硬件 I2C（I2C0，带 ERR_13） |
| DMP 栈 + 直接 yaw | 原始 accel/gyro + 互补滤波 + `yaw_rel`（连续不回绕） |
| `while(mpu_dmp_init())` 无限重试 | 校准 500 有效样本；失败有限返回 |
| 无校准/轴映射/valid | `IMU_STARTUP_SETTLE_MS` + 校准；右手系轴映射；`yaw_rel_valid` 语义 |

## 借鉴建议（应用到本项目）

- **寄存器初始化序列**：P9 实现 `drivers/mpu6050` 时参考其 PWR_MGMT/FS/LPF/Rate 配置（WHO_AM_I 校验、0x68 地址）。
- **不移植 DMP**：本项目 `estimation/attitude` 用互补滤波（`α=τ/(τ+Δt)`）+ 加速度计初始化 roll/pitch + 对校准后 gyro_z 积分得相对 yaw。
- **I2C 传输**：全部走本项目 `i2c_*_blocking`（超时 + 一级恢复），绝不复用其 bit-bang。

## TI 库铁律

TI DriverLib 与生成文件**绝不允许修改**；本项目 IMU 相关适配在 `drivers/mpu6050` + `estimation/attitude` 层。
