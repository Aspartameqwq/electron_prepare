## 严重代码缺陷（SOURCE_FACT）

1. **错误指针转换（多处，非仅一处）**：`MPU_Set_Gyro_Fsr/Accel_Fsr` 用 `(uint8_t*)(fsr << 3)`，`MPU6050_Init` 用 `(uint8_t*)0x80 / (uint8_t*)0x00 / (uint8_t*)0x01` ——全部把**整数值当作内存地址**传入 → 解引用即 UB/崩溃，属严重错误，**初始化整体不可执行**。
2. **`num==0` 下溢**：`MPU6050_ReadData(..., num=0, ...)` 中 `num-1` 下溢为无符号大数 → 越界。
3. **空指针/长度无校验**：写读函数未检查 `data` 空指针与长度范围。
4. **地址硬编码 0x68**。
5. **软件 I2C（bit-bang）无完整总事务时间上限**：`IIC_Start/Stop/WaitAck` 逐位延时，无整体超时。
6. **`while(mpu_dmp_init())` 无限重试**：DMP 初始化失败死循环（200ms 间隔），设备缺失则永久卡死。
7. **`MPU6050_Init()` 返回值与注释相反**：注释与调用语义和实现不一致。
8. **`MPU_Set_Rate()` 覆盖错误码**：后一次写寄存器覆盖第一次的错误返回值。
9. **读取失败无失效语义**：失败后输出数据未标记无效，调用方无法区分成功/失败。
10. **量程与计划不同**：例程 ±2000dps / ±2g，本项目计划 ±500dps / ±4g。

## 可取之处（借鉴）

1. 初始化**意图**可识别：复位（PWR_MGMT_1=0x80）→ 唤醒（0x00）→ 关中断/关 I2C 主模式/关 FIFO → Gyro/Accel FS/LPF/Rate。**但当前实现不可执行**（见缺陷 1/3）；每个寄存器与值必须按**数据手册**重新核对，**禁止直接移植其初始化函数**。
2. `MPU6050ReadID`（WHO_AM_I 校验）思路正确。
3. 原始六轴读取（`MPU6050ReadGyro/ReadAcc` 连读 6 字节）思路正确。

## 借鉴建议（应用到本项目）

- 参考其寄存器初始化序列（P9 实现 `drivers/mpu6050`）；**不移植 DMP 栈**（本项目用原始六轴 + 互补滤波 + 相对 yaw）。
- I2C 全部走本项目 `i2c_*_blocking`（超时 + `recovery_pending`），不复用 bit-bang。
- 校验 WHO_AM_I；缺失设备须**有限超时返回**（禁止无限重试）。
